## 🎯 Part 1: Understand the Student (ICP & Psychographics)

### Ideal Candidate Profile (ICP): "Anxious Arjun"
- **Demographics:** Final-year B.Tech/B.E student (2025/2026 batch) at a Tier-2/3 college (e.g., JNTUH, Anna University affiliated, AKTU, VTU).
- **Core Problem:** Campus placement season is closing in <90 days. Mass recruiters (TCS, Infosys, Wipro, Cognizant) have slashed intake or delayed onboarding. Resumes containing generic 2020 projects (Todo Apps, Calculator, basic Netflix clones) are filtered out in seconds by ATS software.
- **Psychographic Drive:** Arjun doesn't want theory or a ₹30,000 6-month bootcamp. He wants a **tangible, live-deployed AI project** on his resume and GitHub that he can speak about confidently in technical interview rounds this Sunday.

### Psychological Conversion Hooks
1. *"Stop applying with 2020 CRUD projects. Build & deploy a real AI Agent in 60 minutes."*
2. *"Will your resume pass 2026 ATS AI filters? Run the diagnostic scan and fix it this Sunday."*
3. *"Zero ML math or GPU required. Pure, deployable, hands-on production code."*
4. *"Get the exact architecture recruiters are grilling candidates on in technical rounds."*

## 💻 How to Run Locally

This application is built with a lightweight, zero-dependency Node.js HTTP server.

```bash
# 1. Clone or navigate to the directory
cd Nxtwave

# 2. Start the local server
npm start
# or
node server.js
```

Open your browser at:
👉 **`http://localhost:8088`** *(or the next available port automatically detected by `server.js`)*
